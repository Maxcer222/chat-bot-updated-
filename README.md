## ✨ Features
* **Modern UI:** Clean and intuitive chat interface.
* **Theme Toggle:** Support for both Light and Dark modes.
* **Responsive Design:** Optimized for both desktop and mobile devices.
* **Fast Loading:** Built with Vite for superior performance.

## 🛠️ Tech Stack
* **Frontend:** React.js
* **Bundler:** Vite
* **Styling:** CSS3 (with Dark Mode support)
* **Hosting:** AWS S3 (Static Website Hosting)
